The file is written to `obj/<Configuration>/<TargetFramework>/generated/LinkDotNet.BuildInformation/`.

## Using it as a constant

Because most members are `const`, the compiler can remove dead branches and you can use them where constants are required:

```csharp
if (BuildInformation.IsReleaseBuild)
{
    // removed from Debug builds
}

[Obsolete($"Built with {BuildInformation.Configuration}")]
public void Legacy() { }
```

`BuildAt`, `DirectDependencies` and `TransitiveDependencies` are `static readonly` and cannot be used this way.

## Extending the class

The class is `partial`, so you can add your own members next to the generated ones:

```csharp
internal static partial class BuildInformation
{
    public static string Summary => $"{AssemblyName} {AssemblyInformationalVersion} ({Configuration})";
}
```
